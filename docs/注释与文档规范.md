# 文档与注释规范

- README 说明功能、安装、配置、使用方式和已知限制。
- CHANGELOG 记录各版本的功能变化、修复和兼容要求。
- 接口文档描述协议、参数、返回值、错误码和安全边界。
- 源码注释说明行为、约束或必要的技术原因，与代码保持一致。
- 路径示例使用相对路径、环境变量或占位符。
- 提交说明和 PR 描述围绕最终功能、修复及必要验证，使用简洁、准确的表述。
- 文档只保留项目事实和正式成果；私人对话、写作过程、交接提示词、本机记录和个人信息留在本地。
