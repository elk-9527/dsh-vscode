# 明早先看这个

## 一句话

VS Code 侧边栏里的 DSH 面板：**做好了、装好了、测过了**。
打开 VS Code，点左边活动栏里那个 DSH 图标，就能直接跟你的 DSH 说话。

## 建议的操作顺序（这个顺序最理想）

1. **先开 DSH 桌面端**（等它起来）；
2. **再开 VS Code**，点侧边栏的 DSH 图标。

这样面板连的就是你桌面端**正在跑的那一个进程**：一个进程、一个大脑、
同一份记忆、同一份会话记录。这也是你当初选的方案。

如果你反过来（先开 VS Code）：面板会发现桌面端没开门，于是**自己拉一个后台内核**，
用的还是 `desktop` 这个档 —— 记忆、技能、插件完全一样，只是多了一个进程。
两种情况都能用，第一种更干净。

> 为什么先开桌面端才有效：门插件是在**进程启动时**加载的。
> 我今晚把门装进了 desktop 档，但你此刻正在跑的那个桌面端进程是装之前起来的，
> 它还不知道门的存在。**重启一次桌面端（或重启电脑）就到位了。**

## 它到底是什么

就是我桌面上已经配置好的那一个 dsh，不是另起一个 agent。

证据（都是实测）：

- 面板连的那个内核，组合出来的插件树里有你原来的 **13 个插件**：
  记忆（hindsight）、genui、modlens、modsearch、archify、skin-center、
  dshmarket、better-sidebar、dsh-context、auto-approval、turn-rewind，加上门本身。
- 会话的工作目录就是你打开的那个文件夹。
- 记忆和会话数据在 `$DSH_HOME`（`C:\Users\Lenovo\.dsh`）这一层，
  是所有档共用的一份，没有复制、没有另建。

## 这一夜做了什么

**门插件 `dsh-acp-door`**（`packages/dsh-door`）
在你的 DSH 内核上多开一扇只监听本机的 ACP 门（`127.0.0.1:47821`），
这样外部程序才能接上一个**已经在跑**的 DSH。
另外它要替 ACP 会话补挂 agent preset —— 桌面端架构把宿主层工具全关了、
改成每个会话按预设挂，而 ACP 这条路从不点名预设。

**面板扩展 `dsh-panel`**（`packages/vscode-extension`）
活动栏图标 + 侧边栏聊天面板：流式输出、Markdown 渲染、工具调用卡片、
代码改动 diff、上下文用量条、模型切换、中断、权限确认、断线重连。

**测试 6 个套件、约 240 项断言**，一条命令跑完（`node test/run-all.js --all`）：
静态契约 / Markdown 渲染器 / 面板层 / 真浏览器界面 / 兜底拉起 / 端到端真 DSH。

**修掉的真 bug**：

1. Markdown 渲染器遇到「以 ``` 开头但不是合法围栏」的行会**死循环把内存吃光**
   —— 在 webview 里就是把整个面板冻死。模型吐出残缺代码块就会触发。
2. 渲染只依赖 `requestAnimationFrame`，而面板被折叠/隐藏时浏览器会**完全停掉 rAF**
   —— 后台跑完的回合会一直不显示，直到你把面板重新切出来。

**三处加固**：Windows 上收摊改用 `taskkill /T` 杀整棵进程树（不然真正的内核会
变成孤儿进程一直在后台占内存）；自动拉起内核时不再用 `shell:true` 拼参数
（profile 名来自设置项，那是个注入点）；兜底内核对外的网页界面锁死在回环地址。

**第 1 步：把门装进你的 desktop 档**（原计划放到最后的那一步）。
改了什么、备份在哪、怎么卸，都写在 `docs\第1步-装进桌面端.md` 里。

## 需要你知道的几件事

1. **测试在你的共享会话库里留下了一些会话记录。**
   我一条都没删 —— ACP 没有删除会话的接口，而且手删会话文件风险太高。
   如果你想让历史干净，我可以按时间和目录把它们筛出来，给你看过再删。
2. **门没有鉴权**，靠「只监听本机回环」兜底。正式用之前会加口令文件。
3. **权限弹窗你大概率看不到** —— 你的 desktop 档是 `auto-approval`，
   工具调用不会来问。改动的拦截方式我看的是事后 diff（面板里能看到改了什么）。
4. **agent preset 不能中途换**：内核只允许「还没产出任何内容」的会话切预设，
   而 ACP 不暴露这个接口，所以面板里只能换模型，不能换模式。
5. 设置项都在 VS Code 设置里搜 `dshPanel`：地址、端口、自动拉起、兜底档、
   dsh 命令、初始服务商/模型、工作目录。

## 出问题怎么办

- VS Code 里：`Ctrl+Shift+P` → `DSH：显示日志`，会打开输出通道 **DSH Panel**，
  连接、握手、建会话每一步都有记录。
- 还有两个命令：`DSH：新建对话`、`DSH：重新连接`。
- 想确认门在不在：`Test-NetConnection 127.0.0.1 -Port 47821`。
