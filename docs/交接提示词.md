## 这个项目的硬规矩（违反会伤害用户）

1. **绝不修改桌面端的 `desktop` profile**（`$DSH_HOME=C:\Users\Lenovo\.dsh`，
   `profiles/desktop`）。那里是用户在用的记忆/插件。测试一律用 `dshdoor` 档。
2. **不删除用户的任何文件**，包括测试在共享会话库里留下的会话记录。
   要清理必须先问用户。
3. **不破坏编译环境**；保持"零运行时依赖"的风格（手写 NDJSON 客户端、纯 CommonJS

4. **绝不靠进程名去 `taskkill` DSH 内核** —— 用户自己的 DSH Desktop 拉起的内核
   命令行里也有 `--no-open`，跟扩展拉起的长得像。只能收自己开的隔离窗口。
5. **每一步做完提交 git**，提交信息写清"解决了什么问题"，不要写"update"。
6. **不确定就问用户**（他明确要求过）：用通俗的中文、不许用比喻、不要自己拍脑袋。
