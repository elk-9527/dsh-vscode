## 怎么卸回去

```powershell
dsh plugin --profile desktop remove dsh-acp-door
```

然后确认 `package.json` 里 `dsh.profile.bundles` 中的 `"dsh-acp-door"` 也去掉了
（`remove` 一般会一并清掉；没有就手删）。或者直接拿上面的备份覆盖回去：

```powershell

          C:\Users\Lenovo\.dsh\profiles\desktop\ -Force
```

卸掉之后：VS Code 面板就连不上桌面端了，会退化成「自己拉一个后台内核」，

## 一个必须知道的后果

**你此刻正在运行的那个 DSH Desktop 进程，还没有加载门。**

插件是在进程启动时加载的，装包不会插进已经在跑的进程里。
所以现在有两种情况：

- **你先启动 DSH 桌面端，再开 VS Code 面板** → 面板直接连上桌面端那一个进程。
  一个进程、一个大脑，这是最理想的状态。
- **你直接开 VS Code 面板（桌面端没跑或没开门）** → 扩展自己拉一个后台内核，
  用的还是 desktop 这个档，记忆、技能、插件完全一样，只是多了一个进程。

换句话说：**重启一次 DSH 桌面端（或者重启电脑），就进入第一种状态。**
在这之前，第二种也能用，只是会同时存在两个内核。
