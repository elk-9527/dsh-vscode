# 更新记录

本项目大体遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 的写法，
版本号使用 `主.次.修订`。

## [0.1.6] — 2026-09-21

### 变更

- Marketplace 内部名称改为全局未占用的 `dsh-acp-panel`，展示名改为 `DSH ACP Panel`；
  原名称 `dsh-panel` 被市场的全局唯一性检查拒绝，且不属于当前发布者。
- 正式图标改为 DeepSeek 鲸鱼图形：活动栏使用可随主题变化的单色版本，Marketplace 使用冰蓝底、
  品牌蓝鲸鱼与深蓝终端标记，替换原先的占位聊天气泡。

## [0.1.5] — 2026-09-21

### 修复

- ACP 握手和短请求现在都有明确超时；模型回合不设固定总时长，但取消后最多等待 10 秒收尾，
  避免接入点可连接却不应答时面板永久卡住。
- 回合失败只由最外层消息处理器展示一次；主动断开不再误走异常断线与自动恢复流程，
  避免同一个错误出现两张卡片。
- 面板视图销毁后会释放后台 DSH 的使用引用；宽限期内重新打开时重新取得引用，
  既能复用同一进程，也能在无人使用后按设置回收。
- 面板在等待工具权限选择时若被关闭，会立即向内核回答“取消”；视图已不存在时收到的新权限请求
  也会自动取消，避免内核永久等待一个无人能够操作的弹窗。
- 同一回合的多个工具权限请求改为按到达顺序逐个显示，不再互相覆盖；用户停止回合、连接断开或
  面板关闭时会取消队列并清除过期弹窗，避免下一轮误点上一轮的授权。
- 修复中文字符刚好跨越两个 TCP 数据块时被解码成乱码的问题；客户端现使用有状态 UTF-8 解码器。
- 回合进行中不再允许“接回历史”或“新建对话”覆盖当前转录；其它操作报错时也会依据会话真实状态
  保持停止按钮，不再错误地显示为已经空闲。
- ACP 已连接但首次或主动新建会话失败时，会清掉尚未初始化完成的会话和客户端；下一次发送可重新连接，
  不再反复使用没有会话 id 的半成品。若建会话途中直接断线，界面只显示一张错误卡片；按模式自动重建
  失败时也不再错误提示“已重新开启”。
- “把当前文件带进对话”现在会区分磁盘文件与编辑器快照：未保存的新文件、含未保存修改的文件直接携带
  编辑器当前正文，不再发送无法读取或内容过期的文件链接；重复附加同一文件会刷新为最新快照。
- 连续点击“新建对话”会共用同一次切换，发送消息会等待新会话真正建立；快速连续切换模式时按顺序处理，
  最终使用最后一次选择，不再并发关闭/创建同一会话或提示已被后续选择取代的模式成功。
- 连接 `dsh-acp-door` 0.0.14 及以上时，建会话前读取其安全状态；未选择默认模型时直接给出
  可执行的中文提示，避免第一条消息才以内部错误失败。旧版插件仍可兼容连接。

### 工程

- 根目录 `npm test` 现为完整的 24 套件验收入口，不再调用不存在的测试脚本。
- 新增真实 TCP 超时测试、面板生命周期（含关闭时取消待处理权限请求）测试与单次错误展示回归；完整验收覆盖真实浏览器、
  真实 DSH、真实模型回合、工具调用、权限切换、自启内核和断线恢复。

## [0.1.4] — 2026-09-20

### 修复

- 后台启动 DSH 时，网页地址、认证头和常见环境变量形式中的访问凭据不再写入面板日志、
  错误尾部或启动失败详情；敏感参数值替换为「[已隐藏]」，其余诊断信息保留。
- 新增真实子进程回归测试，覆盖标准输出和标准错误输出中的访问凭据。
- 连接目标固定为本机回环地址；工作区设置不能覆盖 DSH 的启动命令、配置集、端口、模型或工作目录。
- 市场 publisher 已确定为 `Elk-ydy`；预发布阶段使用过的占位符扩展 ID 不会被当作正式发布身份。

### 工程

- 快速套件不再隐含启动真实 DSH；真实面板层留在 `--all` 完整验收中，便于在干净环境持续验证。
- 新增 Windows 持续集成：检查可移植的快速套件、换行与两个安装包的构建。
- 市场打包明确排除构建回退目录，避免临时文件进入 VSIX；真窗口自检可从解包后的 VSIX 隔离运行，
  用于核验未安装到日常扩展目录的新发布身份。

## [0.1.3] — 2026-09-20

**权限无法切换时，自动改用面板自行启动的 DSH 实例。** 界面文案中的内部术语（该插件的简称、
包名、版本号、权限预设名、设置项全名）全部移除，改为面向用户的表述。

### 修复

- **连接现有 DSH 实例，但其连接组件版本过低、无法切换权限时**：面板自动改用自行启动的实例
  （该实例的连接组件为新版），权限选择器随即可用。判定逻辑为纯函数
  `shouldSwitchToOwnKernel`，真窗口自检留有完整证据链（切换前记录原因 → 切换后读到权限清单）。
- 切换内核时仅检测本扩展自己的端口，避免将设置项所指向端口上的既有旧版组件误判为「新内核已就绪」，
  从而再次连接到同一实例（该问题由自检发现）。
- 「无法切换权限」的三种原因分别给出对应说明，不再把内核原文混入提示文本。

### 变更

- 界面文案通过黑名单检查：不出现该插件的简称、`dsh-acp-door`、`dsh-base`、`@deepseek-ai/*`、
  `0.0.x`、权限预设名与设置项全名。内核返回的原文不作删改，收在「原始报错（展开）」折叠区
  与日志中。该约束由四个测试保证。
- 版本号与内容对齐（0.1.2 曾有三个内容不同的构建）。

## [0.1.2] — 2026-09-19

- 新增**权限预设选择器**：顶栏列出内核中的权限预设（跟随内核配置，不写死），
  切换完全权限前需先确认。
- 顶部提示与报错文案整体缩短（顶栏状态不超过 24 字；报错标题不超过 32 字，操作建议不超过 48 字）。
- 顶栏配置行按 7:6:6 分配宽度并设置下限，用量条空间不足时换行；面板宽度小于 360px 时收起标签。

## [0.1.1] — 2026-09-19

- 修复关闭面板即终止内核的问题（现象为发送消息后不久断线）：折叠、拖动与重载仅使面板断开连接，
  内核继续运行，在宽限期内重新打开即可继续使用。
- 界面收尾：历史会话列表、用量条、错误卡片原文折叠。

## [0.1.0] — 2026-09-17

- 首个版本：VS Code 侧边栏面板，通过本机 ACP 连接 DSH；端口上没有 DSH 时自行启动一个实例，
  会话记录、记忆与插件与桌面端共用同一份 `$DSH_HOME`。
