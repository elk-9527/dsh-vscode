# 更新记录

本项目大体遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 的写法，
版本号使用 `主.次.修订`。

## [0.1.3] — 2026-09-20

**权限无法切换时，自动改用面板自行启动的 DSH 实例。** 界面文案中的内部术语（该插件的简称、
包名、版本号、权限预设名、设置项全名）全部移除，改为面向用户的表述。

### 修复

- **连接现有 DSH 实例，但其连接组件版本过低、无法切换权限时**：面板自动改用自行启动的实例
  （该实例的连接组件为新版），权限选择器随即可用。判定逻辑为纯函数
  `shouldSwitchToOwnKernel`，真窗口自检留有完整证据链（切换前记录原因 → 切换后读到权限清单）。
- 切换内核时仅检测本扩展自己的端口，避免将设置项所指向端口上的既有旧版组件误判为「新内核已就绪」，
  从而再次连接到同一实例（该问题由自检发现）。
- 「无法切换权限」的三种原因分别给出对应说明，不再把内核原文混入提示文本。

### 变更

- 界面文案通过黑名单检查：不出现该插件的简称、`dsh-acp-door`、`dsh-base`、`@deepseek-ai/*`、
  `0.0.x`、权限预设名与设置项全名。内核返回的原文不作删改，收在「原始报错（展开）」折叠区
  与日志中。该约束由四个测试保证。
- 版本号与内容对齐（0.1.2 曾有三个内容不同的构建）。

## [0.1.2] — 2026-09-19

- 新增**权限预设选择器**：顶栏列出内核中的权限预设（跟随内核配置，不写死），
  切换完全权限前需先确认。
- 顶部提示与报错文案整体缩短（顶栏状态不超过 24 字；报错标题不超过 32 字，操作建议不超过 48 字）。
- 顶栏配置行按 7:6:6 分配宽度并设置下限，用量条空间不足时换行；面板宽度小于 360px 时收起标签。

## [0.1.1] — 2026-09-19

- 修复关闭面板即终止内核的问题（现象为发送消息后不久断线）：折叠、拖动与重载仅使面板断开连接，
  内核继续运行，在宽限期内重新打开即可继续使用。
- 界面收尾：历史会话列表、用量条、错误卡片原文折叠。

## [0.1.0] — 2026-09-17

- 首个版本：VS Code 侧边栏面板，通过本机 ACP 连接 DSH；端口上没有 DSH 时自行启动一个实例，
  会话记录、记忆与插件与桌面端共用同一份 `$DSH_HOME`。
