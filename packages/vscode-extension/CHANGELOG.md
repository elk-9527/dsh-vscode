# 更新记录

本项目遵循大致上的 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 写法，
版本号用 `主.次.修订`。

## [0.1.3] — 2026-09-20

**权限切不动时，自动改用面板自己启动的那个 DSH。** 界面文案里的内部词（「门」、
包名、版本号、档名、设置项全名）全部清掉，改成说人话。

### 修复

- **接上现成的那台 DSH，但它的连接组件太旧、换不了权限时**：面板现在会自动改用
  自己启动的那台（那台的连接组件是新版），权限选择器立刻可用。判据是纯函数
  `shouldSwitchToOwnKernel`，真窗口自检有完整证据链（换之前有原因 → 换完读到权限清单）。
- 换内核时**只盯自己那个端口**，避免把设置里那个端口上现成的旧组件误当成"新内核起好了"，
  于是又接回同一台（自检抓到过）。
- 「换不了权限」的三种原因各说各的话，且不再把内核原文糊在提示里。

### 变更

- 界面文案过黑名单：不出现「门」/ `dsh-acp-door` / `dsh-base` / `@deepseek-ai/*` /
  `0.0.x` / 「档」/ 设置项全名。内核自己吐的原文一字不删，收在「原始报错（点开）」
  折叠区和日志里。有四个测试盯着这条规矩。
- 版本号终于与内容对齐（0.1.2 曾有三个内容不同的构建）。

## [0.1.2] — 2026-09-19

- 新增**权限模式选择器**：顶栏列出内核里的权限预设（跟随内核，不写死），
  完全权限那档先确认再切。
- 顶部提示、报错文案全面改短（顶栏状态 ≤ 24 字；报错标题 ≤ 32 字、怎么办 ≤ 48 字）。
- 顶栏配置行按 7:6:6 分配宽度并设下限，用量条装不下就换行；面板窄于 360px 时收起标签。

## [0.1.1] — 2026-09-19

- 修「关掉面板就杀内核」导致聊两句就断线的问题：折叠/拖动/重载只让面板松手，
  内核继续活着（宽限期内重开就接着用）。
- 界面收尾：历史会话列表、用量条、错误卡片折叠原文。

## [0.1.0] — 2026-09-17

- 第一版：VS Code 侧边栏面板，通过本机 ACP 连接 DSH；端口上没有 DSH 时自己启动一个，
  会话记录、记忆与插件跟桌面端共用同一份 `$DSH_HOME`。
