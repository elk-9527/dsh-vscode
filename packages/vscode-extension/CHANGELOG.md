# 更新记录

本项目大体遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 的写法，
版本号使用 `主.次.修订`。

## [0.18.2] — 2026-10-25

- 更新 DSH `0.2.1-rc.3` 接入与无工具修复兼容说明；需要接入点 `0.6.2`，能力以运行时状态为准。
- 保留当前会话模型、只读修复、差异预览和逐项应用确认流程。

## [0.18.1] — 2026-10-24

- 修复建议改用无工具调度的直接文本生成路径；当前支持 DSH ACP 0.2.1-rc.2，其他内核明确提示能力不可用。保留只读权限、快照核验、差异预览与逐项应用确认。
- 长回答按已完成 Markdown 块保留 DOM，仅更新增长中的尾部；缓存设有预算，结束后释放，并保留稳定段落的文本选区与滚动位置。
- 公共 API revision 3 增加可取消的 generateText，显式报告无工具生成能力和结果。
- 候选安装按原归档逐文件核对字节；发布重新读取预检、候选清单及内核、编辑器、本机原报告和日志，拒绝过期或损坏的证据。

## [0.18.0] — 2026-10-21

- 工作区审查补充有界的实际 Git 差异及当前文件正文；上下文不可用且没有代码检查工具调用时，保持未完成状态。
- 旧式文件链接列出本轮文件名、原地址及可安全转换的本机路径，并明确要求按需读取正文，避免沿用先前选区或其他附件；编辑器正文快照仍保留加入时的内容。
- 修复正文与思考同帧更新、结束尾部及后台刷新；历史和权限窗口统一键盘焦点与取消行为，折叠工具输出按需渲染。
- 修复会话目录移除后的取消，以及不同接入点并发连接的失败隔离；配置准备和插件安装使用可取消的异步进程，并保留部分成功状态。
- 审查明确选择保存相关文件或仅审查磁盘，撤销未保存或已变化文件的旧诊断；支持首次提交前的仓库快照，并对 Git 和文件扫描增加取消、超时及受限并发。
- 已接收队列持久保存，重载后暂停恢复；执行结果未知的消息不会自动重发。草稿写入按目录合并，断线历史区分摘要缓存与不支持的新版磁盘格式。
- 修复草稿写入失败后新草稿的重试、并发移除的回滚和关闭面板时的取回丢失；取回消息先完整保存为草稿，再从队列移除。重连会清理尚在建立的会话，迟到回复不会复用旧连接。
- 增加传输预算、本机运行环境检查及产品模块类型检查。候选安装包、指纹和验收证据统一校验；当前发行组合仍需使用最终候选完成独立验收。

## [0.15.0] — 2026-10-14

- 完整审查报告保存到当前工作区的本地存储，重开窗口后可离线阅读；正文、来源、范围和时间一同保留。历史阅读不连接 DSH，也不扫描原仓库。
- 已保存报告可显式核对当前代码，再将有效位置投影到 Problems。报告保存失败、正文损坏或被清理时明确显示状态。
- 实际应用的修复保留发现引用和应用前后正文。修复前基线、修复验证及后续审查分别建立新的执行记录，沿用一个本地任务归属。
- 修复验证直接选择原工作区测试任务，无需面板聊天轮次。真实退出码、记录文件变化和日志来源分别呈现；支持取消、重测及显式保存用户日志。
- 本地结果采用有界不可变文件、并发写入锁和打开文档保护；增加中断、损坏、容量、多进程、独立验证及窗口重开检查。
- 最低支持版本调整为已通过完整验收的 VS Code 1.141.0。
- 模型提供器就绪后更新已建会话的模型清单；权限按钮在不同系统字体下保持最小点击高度。
- 建立或恢复会话时，在同一个三十秒期限内等待异步模型注册；取消或断线停止重试，其他错误直接返回。
- Windows 优先使用零信号检查内核进程是否存在，受限宿主再进行只读查询；查询失败仍拒绝鉴权。
- 多窗口保存报告时，短暂文件占用重新扫描完整锁选票，选票和等待阶段共用一个五秒期限。

## [0.8.0] — 2026-10-07

- 修复连接取消和并发更换端点时的竞态；公共 API 并发恢复同一会话时共用一次内核恢复，面板切换会话期间等待发送并清理旧消息、工具、用量与预设状态。

- 当前工作区无未提交变更时直接生成范围说明，不调用模型。审查候选提供方限制到变更范围，默认预算为 10 分钟及 40 次工具调用，显示进度和耗时。
- 在本机工作区状态中保留输入和附件草稿，窗口重载和发送失败均可恢复；新输入与待恢复内容分别保留。Windows 同一目录的盘符大小写和分隔符变化不再阻止恢复。

- PR 自动执行代表内核验收；快速套件覆盖 Windows、Linux、macOS，原生编辑器验收覆盖最低版和最新稳定版。

## [0.1.5] — 2026-09-21

### 修复

- ACP 握手和短请求现在都有明确超时；模型回合不设固定总时长，但取消后最多等待 10 秒收尾，
  避免接入点可连接却不应答时面板永久卡住。
- 回合失败只由最外层消息处理器展示一次；主动断开不再误走异常断线与自动恢复流程，
  避免同一个错误出现两张卡片。
- 面板视图销毁后会释放后台 DSH 的使用引用；宽限期内重新打开时重新取得引用，
  既能复用同一进程，也能在无人使用后按设置回收。
- 面板在等待工具权限选择时若被关闭，会立即向内核回答“取消”；视图已不存在时收到的新权限请求
  也会自动取消，避免内核永久等待一个无人能够操作的弹窗。
- 同一回合的多个工具权限请求改为按到达顺序逐个显示，不再互相覆盖；用户停止回合、连接断开或
  面板关闭时会取消队列并清除过期弹窗，避免下一轮误点上一轮的授权。
- 修复中文字符刚好跨越两个 TCP 数据块时被解码成乱码的问题；客户端现使用有状态 UTF-8 解码器。
- 回合进行中不再允许“接回历史”或“新建对话”覆盖当前转录；其它操作报错时也会依据会话真实状态
  保持停止按钮，不再错误地显示为已经空闲。
- ACP 已连接但首次或主动新建会话失败时，会清掉尚未初始化完成的会话和客户端；下一次发送可重新连接，
  不再反复使用没有会话 id 的半成品。若建会话途中直接断线，界面只显示一张错误卡片；按模式自动重建
  失败时也不再错误提示“已重新开启”。
- “把当前文件带进对话”现在会区分磁盘文件与编辑器快照：未保存的新文件、含未保存修改的文件直接携带
  编辑器当前正文，不再发送无法读取或内容过期的文件链接；重复附加同一文件会刷新为最新快照。
- 连续点击“新建对话”会共用同一次切换，发送消息会等待新会话真正建立；快速连续切换模式时按顺序处理，
  最终使用最后一次选择，不再并发关闭/创建同一会话或提示已被后续选择取代的模式成功。
- 连接 `dsh-acp-door` 0.0.14 及以上时，建会话前读取其安全状态；未选择默认模型时直接给出
  可执行的中文提示，避免第一条消息才以内部错误失败。旧版插件仍可兼容连接。

### 工程

- 根目录 `npm test` 现为完整的 24 套件验收入口，不再调用不存在的测试脚本。
- 新增真实 TCP 超时测试、面板生命周期（含关闭时取消待处理权限请求）测试与单次错误展示回归；完整验收覆盖真实浏览器、
  真实 DSH、真实模型回合、工具调用、权限切换、自启内核和断线恢复。
