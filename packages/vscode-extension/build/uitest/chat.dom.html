我看了一下你的 packages/dsh-door/lib/index.js，问题出在服务依赖没有声明。

原因是 cordis 不允许在没有 inject 的情况下读服务属性：

// ❌ 这样会抛：cannot get property "agentPresets" without inject
ctx.on('agent/created', ({ agent }) => ctx.agentPresets.mount(agent, 'standard'));

// ✅ 声明成硬依赖之后就可以读了
export const inject = ['agents', 'agentPresets'];

要点有三个：

  1. 必须声明 inject，cordis 没有「可选依赖」这种写法；
  2. 挂预设是异步的，而第一个 session/prompt 可能比它先到，所以入站要压一下；
  3. 失败要吵 —— 用 try/catch 静默吞掉，就等于把这个坑埋起来。
实测时序：agent/created → +55ms 收到 prompt（压住）→ +357ms 预设挂好 → 放行。
