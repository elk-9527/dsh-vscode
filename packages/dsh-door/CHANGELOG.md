# 更新记录

这个包是一个 DSH 插件：在**正在运行的** DSH 内核上多开一扇只监听本机
（`127.0.0.1`）的 ACP 门，供 VS Code 面板等外部程序连接。

## [0.0.12] — 2026-09-19

- 新增 `dsh-door/permission/get` 与 `dsh-door/permission/set`：把内核
  `dsh-permission-presets` 的权限预设（有哪些档、当前是哪一档）接出来，
  外部客户端因此能在会话中途换权限。写入后**回读真实状态**再返回。

## [0.0.11] — 2026-09-19

- 端口优先读环境变量 `DSH_ACP_DOOR_PORT`：启动内核的一方可把门钉在指定端口上，
  不必再改档里的配置（判定顺序：环境变量 > 档配置 > 默认 47821）。

## [0.0.9] — 2026-09-18

- 修两个 bug：① 建会话失败时留下的预设点名会被**下一次**建会话领走
  （用户没点名却挂上了别的模式）；② 入站闸等预设挂载时的时序问题。

## [0.0.8] — 2026-09-18

- 新增 `dsh-door/sessions/list` 与 `dsh-door/sessions/get`：门只读解析
  `$DSH_HOME/sessions`（含多帧 zstd），让外部客户端能在内核没有列表方法时
  也能列出/接回历史会话。

## [0.0.7] — 2026-09-17

- 支持切换 agent preset（模式）；修「断线接回之后会话没有工具」
  （撞上预设锁时改用工厂期的 `mount()` 补挂）。

## [0.0.5] — 2026-09-16

- 第一版能用的门：把内核的 ACP 传输再挂一份到本机端口上。
