# 更新记录

本包是一个 DSH 插件：在**运行中的** DSH 内核上提供仅监听本机（`127.0.0.1`）的 ACP 接入点，
供 VS Code 面板等外部程序连接。

## [0.2.1] — 2026-10-06

- 为 Provider 上下文提供由 Bridge 确定的客户端身份、显式启动和影响范围确认状态，支持绑定到客户端与工作目录的技能预览计划。
- 保留 Bridge v1 的鉴权、信任、会话匹配和写操作确认边界。
- 历史列表优先通过公开批量标题接口读取，避免逐条完整回放引发重复扫描；选中记录后仍读取完整正文和统计。

## [0.2.0] — 2026-10-02

- 新增 IDE Bridge v1：插件能力注册、受保护端点鉴权、运行记录、取消与事件恢复。
- 同连接 Agent 按会话隔离；提供方异常使用稳定错误，不输出原始异常或凭据。
- 断线时保留进行中的插件任务作用域；编辑器自启内核支持空闲后退出。

## [0.1.2] - 2026-10-01

- 旧 npm 发行物分别记录 DSH 与实际 ACP 版本，覆盖 `DSH 0.1.5-rc.2 / ACP 0.1.5-rc.3` 的依赖解析组合。

- 适配 DSH `0.2.0-rc.2` 的插件兼容检查；保留 `0.1.5-rc.2` 与 `0.2.0-rc.1` 的版本范围。
- 状态接口新增可选的接入协议版本与实际加载的 ACP 包版本，便于区分安装包和运行时。
- 已存在但无法识别的历史服务明确返回不支持，避免错误回退到 v3 读取器并虚报历史能力。
- ACP 会话的工具批准处理器优先检查会话归属，避免请求被已有 Web 处理器接收后等待无人操作的网页。

## [0.1.1] — 2026-09-29

- 接入 DSH 0.2 的进程内 assistant stream，在标准 ACP 提交完整消息之前实时转发正文与思考增量。
- 实时通知按 TCP 客户端持有的会话隔离，且只包含文本；工具参数、provider 原始帧与其它内部数据不会外泄。
- DSH 0.1 或不支持实时事件的内核继续使用标准 ACP 完整消息，无需额外配置。

## [0.1.0] — 2026-09-29

- 兼容 DSH `0.2.0-rc.1`：历史会话改为优先调用公开的 `sessionQuery` 服务，支持 v4 会话格式；
  DSH 0.1 仍保留原有的只读 v3 文件适配。
- 权限预设同时适配 DSH 0.2 的 `catalog/current/resolve/set` 与 DSH 0.1 的
  `selectFor/permissionState/current/set`，外部协议保持不变。
- 状态方法新增 `historyKind`、`sessionFormat` 与 `permissionKind`，方便客户端和日志明确显示
  当前使用的内核适配路径。
- 首次运行且会话目录尚未创建时，历史列表返回空清单，不再把正常的空状态报告成错误。
- 对 DSH 内核的 peer dependency 扩展为 `0.1.5-rc.2 || 0.2.0-rc.1`。

## [0.0.16] — 2026-09-21

- 成功建立或恢复会话后立即释放仅供请求阶段使用的队列与索引，避免同一连接长期运行时持续积累
  已经失效的恢复记录。
- 成功关闭会话后同步释放该连接中的挂载、等待与恢复状态；关闭失败时保留仍然有效的会话状态。
  跨连接的会话预设记忆不受影响，之后仍可按原预设恢复持久会话。

## [0.0.15] — 2026-09-21

- 插件卸载、DSH 重载或退出时显式关闭所有仍连接的客户端 socket，不再留下“看似连接、实际无人应答”的
  半开连接。
- 单个连接的拆除或 socket 销毁失败不会中断其余连接的清理；两类失败均写入内核日志供排查。

## [0.0.14] — 2026-09-21

- 新会话默认跟随 DSH 设置中当前选择的模型，不再把开发机器上的服务商和模型写进安装包。
  同时填写 `provider` 与 `model` 仍可固定该接入点；只填一项会被忽略，避免拼出混合配置。
- 新增只读 `dsh-door/status` 方法，报告插件版本、初始模型是否就绪、模型来源和可选能力；
  状态中不包含 API key、环境变量值或设置文件路径。
- 修复冷启动竞态：未显式固定模型时，接入点会等待 DSH 用户设置加载完成后再监听，避免首次连接
  短暂取得基础默认模型、随后因服务商凭据不匹配而失败。旧版 DSH 最多等待 5 秒后继续兼容路径。
- 新增模型选择、状态脱敏和版本一致性测试，并在真实 DSH 中验证动态默认模型、工具调用与恢复。

## [0.0.13] — 2026-09-20

- 固定接入点的监听地址为 `127.0.0.1`：配置中的其它 `host` 值会被拒绝并记录诊断，避免在没有鉴权的情况下意外暴露到局域网。
- 诊断报文中的自称由该插件的内部简称改为「该插件」：方法不存在时返回
  `该插件不支持 <method>（插件版本过低或方法名不符）`，方法名不属于权限方法时返回
  `该插件不认识权限方法 <method>`。错误码不变（均为 `-32601`）。
- 依赖该报文的客户端需同时识别旧文本与新文本：面板侧的分档正则已包含两个版本
  （见 `packages/vscode-extension/src/dsh/permission.js`），因此不要求用户先升级插件。

## [0.0.12] — 2026-09-19

- 新增 `dsh-door/permission/get` 与 `dsh-door/permission/set`：将内核 `dsh-permission-presets`
  的权限预设（可用项与当前项）暴露给外部客户端，使其可在会话进行中切换权限。
  写入后**回读真实状态**再返回。

## [0.0.11] — 2026-09-19

- 端口优先读取环境变量 `DSH_ACP_DOOR_PORT`：启动内核的一方可将接入点固定在指定端口上，
  无需修改档内配置（判定顺序：环境变量 > 档配置 > 默认 47821）。

## [0.0.9] — 2026-09-18

- 修复两个问题：① 建会话失败时遗留的预设点名会被**下一次**建会话取用（用户未指定却挂载了其它模式）；
  ② 入站闸等待预设挂载时的时序问题。

## [0.0.8] — 2026-09-18

- 新增 `dsh-door/sessions/list` 与 `dsh-door/sessions/get`：该插件只读解析 `$DSH_HOME/sessions`
  （含多帧 zstd），使外部客户端在内核没有列表方法时也能列出或接回历史会话。

## [0.0.7] — 2026-09-17

- 支持切换 agent preset（模式）；修复断线接回后会话没有工具的问题
  （遇到预设锁时改用工厂期的 `mount()` 补挂）。

## [0.0.5] — 2026-09-16

- 首个可用版本：将内核的 ACP 传输再挂载一份到本机端口上。
